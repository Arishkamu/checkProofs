data Conversion #

Represents a conversion between two Core expressions.

The conversion stores:

  • the left-hand side expression
  • the right-hand side expression
  • information about operation

data PostlDef #

Represents a postulate definition ready for rewrite rule.

The field pstl_fid identifies the head function appearing on the left-hand side of the rule.

data CheckerST #

Global mutable checker state.

This state is threaded through the checker monad and stores all discovered declarations, conversions, postulates, and environment information.
